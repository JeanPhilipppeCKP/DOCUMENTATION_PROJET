    🔒 Sécurité — RLS & TREATAS¶

    Cette page explique qui voit quoi dans le modèle. La sécurité au niveau des lignes (RLS) limite les données visibles selon le rôle de l'utilisateur connecté.

    Vue d'ensemble : qui accède à quoi ?¶

    Table admin reader
    AGG_OBJ_OPPORTUNITIES ✅ Accès total 🔒 Filtré
    DIM_CUSTOMER ✅ Accès total 🔒 Filtré
    DIM_ENTITY ✅ Accès total 🔒 Filtré
    DIM_PRODUCT ✅ Accès total 🔒 Filtré
    FACT_OPP_PBM ✅ Accès total 🔒 Filtré

    Détail par rôle¶

    🔐 Rôle : admin¶

    Tout accès

    Ce rôle n'a pas de restriction de lignes — accès complet à toutes les tables.

    🔐 Rôle : reader¶

    Droit de lecture

    Table : AGG_OBJ_OPPORTUNITIES¶

    🔁 Mécanisme : Filtre RLS standard

    Expression appliquée :

    VAR Sectors =
    CALCULATETABLE(
        VALUES(sami_security[sector_name]),
        sami_security[cuid_user] = RIGHT(USERNAME(),8)
    )

VAR nb_sectors = COUNTROWS(Sectors)


RETURN if(nb_sectors <2, OR(
                "all_sectors" IN Sectors,
                AGG_OBJ_OPPORTUNITIES[sector_agency] IN Sectors
            ), TRUE() )

    Table : DIM_CUSTOMER¶

    🔁 Mécanisme : Filtre RLS standard

    Expression appliquée :

    VAR Groups =

    CALCULATETABLE(

        VALUES(sami_security[group_code]),

        sami_security[cuid_user] = RIGHT(USERNAME(),8)

    )

    VAR Sectors =

    CALCULATETABLE (

        VALUES ( sami_security[sector_name] ),

        sami_security[cuid_user] = RIGHT ( USERNAME (), 8 )

    )

RETURN

    AND(

        OR(

            "all_groups" IN Groups,

            DIM_CUSTOMER[group_code] IN Groups

        )

    ,

        OR (

            "all_sectors" IN Sectors,

            DIM_CUSTOMER[sector_agency] IN Sectors

        )

    )

    Table : DIM_ENTITY¶

    🔁 Mécanisme : Filtre RLS standard

    Expression appliquée :

    VAR Entity =
   CALCULATETABLE(
       VALUES(sami_security[entity_code]),
      sami_security[cuid_user] = RIGHT(USERNAME(),8)
      )
RETURN
    OR(
        "all_entities" IN Entity,
        DIM_ENTITY[Entity] IN Entity
    )

    Table : DIM_PRODUCT¶

    🔁 Mécanisme : Filtre RLS standard

    Expression appliquée :

    VAR BusinessLines =
    CALCULATETABLE(
        VALUES(sami_security[business_line]),
        sami_security[cuid_user] = RIGHT(USERNAME(),8)
    )
    VAR SubBusinessLines =
    CALCULATETABLE(
        VALUES(sami_security[sub_business_line]),
        sami_security[cuid_user] = RIGHT(USERNAME(),8)
    )
RETURN
    AND(
        OR(
            "all_business_lines" IN BusinessLines,
            DIM_PRODUCT[business_line] IN BusinessLines
        )
    ,
        OR(
            "all_sub_business_lines" IN SubBusinessLines,
            DIM_PRODUCT[sub_business_line] IN SubBusinessLines
        )
    )

    Table : FACT_OPP_PBM¶

    🔁 Mécanisme : Filtre RLS standard

    Expression appliquée :

    VAR owner = USERNAME()

VAR manager =
    CALCULATETABLE(
        VALUES(sami_security_bm_manager[owner_cuid]),
        sami_security_bm_manager[owner_manager_cuid] = RIGHT(owner,8)
    )

RETURN
AND (
  FACT_OPP_PBM[close_date] >= edate(today(),-9),

  OR(     
    AND (
        FACT_OPP_PBM[opportunity_owner_cuid] = owner,
        RIGHT(FACT_OPP_PBM[opportunity_owner_cuid],8) IN manager
    ),
    OR(
        RIGHT(FACT_OPP_PBM[opportunity_owner_cuid],8) IN manager,
        FACT_OPP_PBM[opportunity_owner_cuid] = owner) 
)   
)
